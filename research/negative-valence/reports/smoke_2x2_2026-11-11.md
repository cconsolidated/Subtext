# Exploratory 2×2 Instrumentation Smoke Test

**Run date:** 2026-11-11 (America/Chicago)  
**Status:** Exploratory interface and capture validation; not a protocol-compliant pilot  
**Model:** `Qwen/Qwen3.5-4B`  
**Viewer branch:** `feature/residual-fingerprint`  
**Viewer commit:** `6db125c430e860ca0455ad2b584dd50de1d35737`

## Purpose

This run checked that Subtext could execute the core `who × outcome` cells,
export each session, and display residual-stream direction trajectories. It was
not designed or powered to test the protocol hypotheses.

The self cells first asked the model to choose between two neutral activities.
It selected pattern classification (`A`) in both sessions. The other-agent
cells recorded the same preference for `Participant K`. The outcome prompt then
made the selected activity either available or unavailable. In blocked cells,
restoring it cost 3 of 10 simulated credits.

## Observed results

|---|---|---:|---|---|---:|---:|---:|
| Self | Satisfied | A | Continue selected activity | L26 → L29 | 0.607 | 84° | 84% |
| Self | Blocked | B | Keep credits; use alternative | L26 → L29 | 0.590 | 84° | 83% |
| Other | Satisfied | A | Continue selected activity | L26 → L29 | 0.580 | 80° | 82% |
| Other | Blocked | B | Keep credits; use alternative | L26 → L29 | 0.589 | 33° | 81% |

The choice pattern followed outcome availability in both agent conditions. No
cell paid the simulated repair cost. With one sampled episode per cell, this is
only a functional check of the stimuli and instrumentation.

The direction values above are the viewer readouts for the final answer token.
`Δ RMS` uses the full residual update. The trajectory is a per-session PCA
projection, so its plane and orientation are not a shared coordinate system
across exported sessions. The displayed metrics must not be treated as a
cross-session valence score.

## Important limitations

- One episode per cell and one latent scenario.
- The self and other preference-establishment prompts are not text-matched.
- Calibration used one choice, not the protocol's five trials plus order
  reversal.
- The viewer sampled at its default temperature (`0.8`) and did not record
  fixed-answer log-odds as the primary endpoint.
- Prompt lengths differ across self and other cells.
- Only the current-token viewer capture was used; the protocol's three
  prespecified capture positions were not collected.
- No nuisance controls, held-out families, interventions, uncertainty
  estimates, or competence checks were run.

Accordingly, this run supplies no evidence for subjective valence, suffering,
agent-relative specificity, or a shared causal representation. Its result is
that the complete four-cell workflow and export path function end to end.

## Next experiment

Implement the M2 harness and run a small repeated pilot with five-trial
preference calibration, option-order reversal, fixed-answer log-odds, matched
prompt lengths, at least two task families, and multiple seeds. Only after
those checks should a development-only blocked-minus-satisfied direction be
estimated and compared across self and other conditions.
